\# Mobile Sales Analysis Dashboard - Power BI



\## Project Overview



This project analyzes mobile sales data and provides business insights using Microsoft Power BI.



The dashboard helps to understand sales performance, customer trends, product performance, and revenue analysis.



\## Tools Used



\- Microsoft Power BI

\- Excel / CSV Dataset

\- Data Visualization



\## Dataset Information



The dataset contains mobile sales details including:



\- Mobile Brand

\- Model

\- Price

\- Sales Quantity

\- Revenue

\- Region

\- Date Information



\## Dashboard Features



\- Total Sales KPI

\- Total Revenue Analysis

\- Brand-wise Sales Performance

\- Model-wise Analysis

\- Region-wise Sales Analysis

\- Sales Trend Visualization



\## Key Insights



\- Identified top-performing mobile brands

\- Analyzed sales trends

\- Compared product performance

\- Studied regional sales distribution
